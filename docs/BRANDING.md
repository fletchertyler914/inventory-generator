# CaseSpace Branding Guidelines

## Product Name

**Primary Name**: CaseSpace  
**Tagline/Subtitle**: "The Case Agent" (for marketing emphasis, AI-powered positioning)

**Usage**:
- **CaseSpace** - Primary product name in all documentation, UI, and technical references
- **"The Case Agent"** - Marketing tagline emphasizing the AI-powered, automated nature
- Can be used together: "CaseSpace - The Case Agent" for marketing materials
- **Elevator Pitch Context**: When using the elevator pitch, "CaseSpace" or "The Case Agent" can be used interchangeably

## Brand Positioning

### Elevator Pitch

**"No more Word docs, Excel sheets, digging through files and folders, needing special software to open different file types, and manual analyzing and writing long, tedious reports. CaseSpace helps with all of this and more."**

### Core Brand Promise

**"Replace your toolkit. Not add to it."**

CaseSpace doesn't supplement your existing tools—it replaces them:
- **Replaces Word**: Rich text editing, notes, and AI-generated reports
- **Replaces Excel**: Schema-driven inventory and data management
- **Replaces File Explorer**: Intelligent file organization and search
- **Replaces Specialized Viewers**: One viewer for all file types
- **Replaces Manual Analysis**: AI-powered extraction and insights
- **Replaces Report Writing**: AI-generated comprehensive reports

## Brand Personality

### Attributes

1. **Intelligent**: AI-powered automation and insights
2. **Unified**: One workspace, multiple tools replaced
3. **Efficient**: Eliminates context switching and manual work
4. **Professional**: Production-grade quality for serious work
5. **Intuitive**: Deeply embedded features that feel natural
6. **Powerful**: Handles enterprise-scale workloads effortlessly

### Voice & Tone

- **Direct**: Clear, no-nonsense communication
- **Confident**: Bold claims backed by capabilities
- **Empowering**: Focus on what users can accomplish
- **Future-Focused**: Emphasizes AI and automation
- **Professional**: Serious tool for serious professionals

## Competitive Differentiation

### vs. Word + Excel + File Explorer

**Traditional**: Three separate applications, manual data entry, copying between apps
**CaseSpace**: One unified workspace, automated inventory, AI-generated reports

### vs. Document Management Systems

**DMS**: Enterprise complexity, cloud-dependent, no AI, no time tracking
**CaseSpace**: Simple, local-first, AI-powered, integrated time management

### vs. AI Tools

**AI Tools**: Standalone, no workflow integration, no file management
**CaseSpace**: Deep AI integration throughout workflow, unified file management

## Usage Guidelines

### Do's ✅

- ✅ Emphasize "replaces" not "works with"
- ✅ Highlight elimination of context switching
- ✅ Focus on AI automation and intelligence
- ✅ Use "The Case Agent" tagline for AI emphasis
- ✅ Show before/after workflows
- ✅ Highlight time savings and efficiency

### Don'ts ❌

- ❌ Don't position as "another tool to add"
- ❌ Don't minimize the replacement value
- ❌ Don't downplay AI capabilities
- ❌ Don't focus only on file management
- ❌ Don't ignore the time tracking value
